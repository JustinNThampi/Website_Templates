# Website Templates

A collection of modern, responsive, and reusable website templates designed and developed by **Justin N Thampi**.

These templates are created for developers, designers, students, freelancers, and anyone looking for a clean starting point for a website project.

## 🚀 Templates

The repository currently includes templates for different website use cases, including:

* SaaS Landing Pages
* Business Websites
* Portfolio Websites
* Landing Pages
* More templates coming soon

Each template is designed to be:

* 📱 Responsive across different screen sizes
* ⚡ Lightweight and fast
* 🎨 Modern and professional
* 🧩 Easy to customize
* 💻 Built with clean HTML, CSS, and JavaScript
* 🌐 Ready to deploy

## 📥 How to Use

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/website-templates.git
```

### 2. Open a template

Navigate to the template you want to use:

```text
templates/
```

Then open its `index.html` file in your browser.

### 3. Customize

You can modify:

* Text and content
* Colors
* Fonts
* Images
* Layouts
* Sections
* Navigation
* Animations
* JavaScript functionality

No complicated setup is required for the basic HTML/CSS/JavaScript templates.
